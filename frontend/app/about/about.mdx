## Some things I've worked on

- **Cut our Next.js memory from ~5 GB to ~1.2 GB per pod** by tracking down a react-query timer that kept every server-rendered request alive. [The write-up](/thoughts/ssr-requests-still-alive) was featured in [This Week in React](https://thisweekinreact.com/newsletter/305) and [TLDR Dev](https://tldr.tech/dev/2026-11-12), and led to a [docs PR to TanStack Query](https://github.com/TanStack/query/pull/12589).
- **Run an AI coding agent inside my cluster** in a Kata microVM, with read-only access and PR-only Git, and hand it tasks from my phone. [How it works](/thoughts/running-ai-agents-in-kubernetes).
- **Run this site on my own k3s cluster**, with an arguably over-engineered stack:
  1. k3s
  2. GitOps via Argo CD
  3. Vault in HA
  4. External Secrets Operator
  5. Helm and Kustomize
  6. kube-prometheus-stack with Loki
  7. Ansible
  8. Linkerd for service mesh
  9. Core Web Vitals and error monitoring via BullMQ + Postgres + Grafana

More on all of this in the [archive](/archive) and the [homelab](/homelab) page.

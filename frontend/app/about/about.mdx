After several years on the frontend, I've been working my way down the stack into infrastructure, observability and platform engineering. This site is where I practise. It runs on a small, arguably over-engineered k3s cluster that I run myself:

1. k3s on three VPS nodes, deployed with GitOps through Argo CD
2. Canary releases with Argo Rollouts
3. Vault and External Secrets Operator for secrets
4. kube-prometheus-stack and Loki for metrics, logs and alerts
5. Ansible to set up and harden the nodes
6. Core Web Vitals and error monitoring, built with BullMQ, Postgres and Grafana
7. An AI agent in a Kata microVM that I hand tasks to [from my phone](/thoughts/running-ai-agents-in-kubernetes)

The [homelab page](/homelab) shows it live, the [uses page](/uses) lists the full stack, and the cluster's GitOps repo is [public on GitHub](https://github.com/rohitpotato/k8s-apps).
